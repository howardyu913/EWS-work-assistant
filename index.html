      📋 接入流程（你已有组织，跳过第1步）：

      创建企业自建应用
      访问 open.feishu.cn → 开发者后台 → 创建企业自建应用
      开通权限
      权限管理 → 开通权限 → 搜索 bitable → 勾选「查看、评论、编辑和管理多维表格」→ 确认开通
      发布应用
      版本管理与发布 → 创建版本（1.0.0）→ 保存 → 申请发布（你是管理员，直接通过）
      给表格授权
      打开客诉多维表格 → 右上角「...」→「更多」→「添加文档应用」→ 搜索你的应用 → 添加
      填写下方凭证
      在应用「凭证与基础信息」获取 App ID 和 Secret，从表格 URL 提取 App Token 和 Table ID
